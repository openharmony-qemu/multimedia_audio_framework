# 离线编辑

## 范围

离线编辑使用 `AUDIOSUITE_PIPELINE_EDIT_MODE`，对已录制或生成好的 PCM 数据逐帧处理，支持全部效果节点。输入由应用通过输入节点回调提供，输出由应用通过 `RenderFrame()` 或 `MultiRenderFrame()` 取回。管线模型见 [管线.md](../pipeline/管线.md)，节点类型和效果参数见 [节点.md](../node/节点.md)。

## 设计规格

### 典型流程

1. 创建引擎和编辑模式管线。
2. 通过 builder 创建输入节点、效果节点和输出节点，并按顺序连接。
3. 设置输入节点格式和取数回调、输出节点格式。
4. 调用 `StartPipeline()`。
5. 逐帧调用 `RenderFrame()`；含多输出节点时调用 `MultiRenderFrame()`。
6. 所有输入结束后继续渲染，直到 `finishedFlag` 为 true。
7. 调用 `StopPipeline()`，按相反顺序销毁节点、管线和引擎。

### 输入回调

- 只有输入节点可以设置取数回调；输出节点设置回调返回 `AUDIOSUITE_ERROR_UNSUPPORTED_OPERATION`，输入节点未设置回调时创建返回 `AUDIOSUITE_ERROR_REQUIRED_PARAMETERS_MISSING`。
- 回调返回值必须在 `[0, audioDataSize]` 内：小于 0 按 0 处理，大于上限按上限截断。
- 最后一帧必须把 `finished` 置为 true；设置后管线不再向该输入节点取数。

### 渲染与结束条件

- `RenderFrame()` 的 `audioData` 由应用分配，`requestFrameSize` 和 `responseSize` 单位为字节；管线尽量按请求大小填充，实际写入量通过 `responseSize` 返回。
- 所有输入结束后，管线完成剩余处理和缓存数据，再通过 `finishedFlag` 通知应用。
- `finishedFlag` 为 true 后不得继续调用渲染接口，否则返回 `AUDIOSUITE_ERROR_UNSUPPORTED_OPERATION`。
- 管线含音源分离节点时必须使用 `MultiRenderFrame()`：数组元素数量为 2（人声、伴奏），每路缓冲区大小一致，系统保证各路写入长度相同。

### 帧规格

- 默认单帧时长 20 ms；采样率 11025 Hz 时按 40 ms 计算。
- 11025 Hz 输入节点内部转换到 16 kHz、F32LE 处理，输出节点使用双倍帧长。
- 请求帧大小应与输出格式的采样率、声道数和采样字节数匹配；帧长变化会影响响应大小和内部缓存。

### 元数据渲染

- 系统接口 `OH_AudioSuiteEngine_MetaRenderFrame()` 可在同一帧中传递音频和元数据；`OH_AudioSuite_MetaFrame` 的 `audioData`、`metaData` 及对应 size 都必须非空且大于 0。

## 约束与常见误区

- 离线编辑不是"一次性处理整段音频"：必须反复调用渲染接口，直到 `finishedFlag` 为 true。
- 管线停止状态下不能渲染；停止会清空节点缓存，但不会断开连接。
- 含多输出节点时必须使用 `MultiRenderFrame()`，`RenderFrame()` 取不到全部输出。
- HOA 空间渲染节点的前置节点必须是 HOA 格式输入节点，连接不合法时错误到 `StartPipeline()` 才暴露。
- 渲染期间不要修改节点连接或释放输入缓冲区。

## 安全与隐私

- 输入回调返回的缓冲区必须在本次渲染调用返回前保持有效；管线不复制应用未提交的数据。
- 校验 `requestFrameSize`、`responseSize` 和回调返回值，避免越界读写。
- 用户音频和中间结果按敏感数据处理，日志和快照不得输出原始 PCM。
