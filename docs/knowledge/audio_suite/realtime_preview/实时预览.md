# 实时预览

## 范围

实时预览使用 `AUDIOSUITE_PIPELINE_REALTIME_MODE`，把 AudioSuite 处理结果直接写入 `OH_AudioRenderer` 的播放缓冲区，适用于效果试听和实时创作。实时算法处理在应用进程内完成，播放链路由 Renderer 负责；离线批量处理见 [离线编辑.md](../offline_editing/离线编辑.md)，管线模型见 [管线.md](../pipeline/管线.md)。

## 设计规格

### 模式与版本

- API 22：实时预览只支持均衡器节点。
- API 23 起：实时预览支持全部效果节点。
- 工作模式在创建管线时确定；编辑模式与实时模式不能在同一管线内切换。

### 与 Renderer 集成

- 应用创建 `OH_AudioRenderer`，在写数据回调中调用 `OH_AudioSuiteEngine_RenderFrame()`，把处理结果写入 Renderer 提供的缓冲区。
- Renderer 的采样率、声道布局和采样格式应与管线的输出节点格式一致。
- Renderer 回调帧长应与管线单帧长度保持一致：默认 20 ms，11025 Hz 时 40 ms；帧长不匹配会产生额外缓存或时延。
- 实时预览管线不能替代 Renderer 的流生命周期管理；Renderer 暂停、停止或设备切换时，应同步停止或重建管线。

### 线程与性能

- 实时模式通过 AudioWorkgroup 提升渲染线程优先级，帧周期为 20 ms。
- 管线处理耗时随效果节点数量增加；节点过多会导致 Renderer 欠载、卡顿或丢帧。
- 节点能力配置中的 `realtimeFactor` 描述实时负载系数；DFX 以 1.0、1.1、1.2 倍帧时长阈值统计超时次数，用于定位性能问题。
- 写回调中不要执行阻塞操作、内存分配或图变更；参数更新应尽量在非渲染线程完成。

### 拓扑与参数

- 建议在管线停止状态完成节点增删和连接调整；运行期拓扑变更受连接检查约束并可能造成数据丢失。
- 运行期开关节点参与渲染使用 `OH_AudioSuiteEngine_BypassEffectNode()`，不要通过改图实现。
- 参数设置（如均衡器增益、声场类型）可在运行中生效，但不要在 `OH_AudioSuite_RequestRenderDataCallback` 中调用引擎接口。

## 约束与常见误区

- 实时预览不是低时延保证：节点数量、算法实时系数和设备负载都会影响播放稳定性。
- 不要按离线编辑的方式一次性把整段音频写入 Renderer；必须按 Renderer 回调逐帧处理。
- 实时预览的拓扑调整应放在停止状态；运行期改图可能造成数据丢失或连接失败。
- 采样率 11025 Hz 时必须按 40 ms 帧长与 Renderer 对齐，否则会出现节奏或时延问题。
- 管线停止后 Renderer 不应继续调用渲染接口；`finishedFlag` 为 true 后同样不得继续渲染。

## 安全与隐私

- 校验 Renderer 回调传入的缓冲区长度和格式；不要信任外部帧长。
- 处理失败或 Renderer 停止后不得残留未释放的管线、节点或回调。
- 用户音频和实时处理结果按敏感数据处理，日志和快照不得输出原始 PCM。
