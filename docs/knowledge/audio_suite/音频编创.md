# 音频编创

## 范围

音频编创聚焦 AudioKit 对外提供的 OHAudioSuite C API（`libohaudiosuite.so`，系统能力 `SystemCapability.Multimedia.Audio.SuiteEngine`），以及在实现仓中承载它的 `frameworks/native/ohaudiosuite/` 和 `services/audio_suite/`。内容覆盖引擎、管线、节点编排、效果参数、渲染驱动、PCM 格式转换和云端算法资源下载。实时音频引擎和在线音效的处理边界见 [音频引擎.md](../audio_engine/音频引擎.md)，播放与录制会话见 [音频播放.md](../audio_stream/audio_renderer/音频播放.md) 和 [音频录制.md](../audio_stream/audio_capturer/音频录制.md)。

## 版本与接口边界

OHAudioSuite 的能力按 API 版本分批开放，公开接口和系统接口（头文件标注 `@systemapi`）必须分开描述。

| API 版本 | 新增能力 | 接口性质 |
| --- | --- | --- |
| 22 | 引擎、管线、节点、均衡器、降噪、声场、音源分离、声音美化、环境效果、混音；离线编辑与实时预览 | 公开 |
| 23 | 空间渲染、传统变声、通用变声、变速变调；实时预览支持全部效果节点 | 公开 |
| 26.0.0 | PCM 格式转换器；运行时快照；元数据渲染帧、系统节点、系统节点参数；云端算法资源下载管理 | 转换器与运行时快照公开，其余 `@systemapi` |
| 26.0.1 | 批量查询特性安装状态、下载状态和新版本信息 | `@systemapi` |
| 26.2.0 | 无管线节点直连链（`CreateNodeDirect`、`RenderDirect`、`Render`）、链级输入输出格式、节拍器参数与 profile 缓冲 | `@systemapi` |

- 非系统应用调用 `@systemapi` 接口返回 202，不得把系统接口描述为三方应用能力。
- 节点类型是否可用还受设备算法能力、产品配置和构建开关约束。创建节点前必须调用 `OH_AudioSuiteEngine_IsNodeTypeSupported()` 检查；音源分离依赖 NPU，混音节点在实现上恒支持。
- 接口声明以 `interface_sdk_c/multimedia/audio_framework/audio_suite_engine/` 为准，只有列入 `ohaudiosuite.ndk.json` 的符号才会随 SDK 发布。26.2.0 的无管线链和节拍器接口在本仓实现未接入前，不得按已交付能力使用。

## 设计规格

### 引擎、管线与节点模型

- 引擎是进程级单例，统一管理管线、系统节点和直连节点链。重复创建返回 `AUDIOSUITE_ERROR_INVALID_STATE`，未创建时销毁同样返回该错误。
- 管线是音频编创的执行单元，承载节点组网和渲染状态；一个引擎最多创建 10 条管线。
- 节点是处理单元，本身不能独立工作，必须属于某条管线，或属于系统接口的无管线直连链。
- 数据流采用反向驱动：应用调用 `RenderFrame()` 或 `MultiRenderFrame()` 后，输出节点逐级向上游请求数据，最终由输入节点的 `OH_InputNode_RequestDataCallback()` 回调向应用取 PCM 数据。
- 生命周期顺序为创建引擎、创建管线、创建并连接节点、启动管线、逐帧渲染、停止管线、销毁节点/管线/引擎；释放顺序与创建顺序相反。

### 管线规格

| 项 | 规格 |
| --- | --- |
| 工作模式 | `AUDIOSUITE_PIPELINE_EDIT_MODE`：离线编辑，支持全部效果节点；`AUDIOSUITE_PIPELINE_REALTIME_MODE`：实时预览，API 22 只支持均衡器，API 23 起支持全部效果节点 |
| 状态 | `AUDIOSUITE_PIPELINE_STOPPED`：初始状态或停止后，节点缓存被清空；`AUDIOSUITE_PIPELINE_RUNNING`：启动后 |
| 完整性 | 每条管线至少 1 个输入节点，有且只有 1 个输出节点；`StartPipeline()` 检查连接有效性和节点连接错误 |
| 拓扑 | `StopPipeline()` 不改变节点连接关系；启动、停止、连接、断开和移除节点必须在合法状态下操作 |
| 实时预览数量 | API 26.0.0 之前实时预览管线最多 1 条；26.0.0 及以后不再单独限制，但管线总数仍不得超过 10 条 |

### 节点与连接规格

节点分为输入节点、效果节点和输出节点。效果节点的输出格式由节点类型固定，只有输入节点和输出节点可以通过 builder 或 `SetAudioFormat()` 设置格式。

| 节点类型 | 值 | 起始版本 | 节点输出格式 | 关键约束 |
| --- | --- | --- | --- | --- |
| `INPUT_NODE_TYPE_DEFAULT` | 1 | 22 | 由应用设置 | 必须设置取数回调 |
| `OUTPUT_NODE_TYPE_DEFAULT` | 101 | 22 | 由应用设置 | 每条管线仅 1 个 |
| `EFFECT_NODE_TYPE_EQUALIZER` | 201 | 22 | 48 kHz、S16LE、2 声道 | 10 频段增益 |
| `EFFECT_NODE_TYPE_NOISE_REDUCTION` | 202 | 22 | 16 kHz、S16LE、1 声道 | 无参数，仅支持旁路 |
| `EFFECT_NODE_TYPE_SOUND_FIELD` | 203 | 22 | 48 kHz、S16LE、2 声道 | 4 种声场 |
| `EFFECT_MULTII_OUTPUT_NODE_TYPE_AUDIO_SEPARATION` | 204 | 22 | 48 kHz、F32LE、4 声道（前 2 声道人声，后 2 声道伴奏） | 只能连接输出节点，每管线 1 个，依赖 NPU |
| `EFFECT_NODE_TYPE_VOICE_BEAUTIFIER` | 205 | 22 | 48 kHz、S16LE、2 声道 | 4 种美化类型 |
| `EFFECT_NODE_TYPE_ENVIRONMENT_EFFECT` | 206 | 22 | 48 kHz、S16LE、2 声道 | 4 种环境 |
| `EFFECT_NODE_TYPE_AUDIO_MIXER` | 207 | 22 | 采样率随配置、F32LE、2 声道 | 唯一支持多路输入的效果节点，每管线最多 3 个 |
| `EFFECT_NODE_TYPE_SPACE_RENDER` | 208 | 23 | 48 kHz、S16LE、2 声道 | 固定摆位、旋转、扩展三种模式，左手坐标系 |
| `EFFECT_NODE_TYPE_PURE_VOICE_CHANGE` | 209 | 23 | 16 kHz、S16LE、1 声道 | 性别、类型、音调三项配置 |
| `EFFECT_NODE_TYPE_GENERAL_VOICE_CHANGE` | 210 | 23 | 48 kHz、S16LE、2 声道 | 10 种风格化类型 |
| `EFFECT_NODE_TYPE_TEMPO_PITCH` | 211 | 23 | 48 kHz、S16LE、1 声道 | 变速与变调独立设置 |
| `EFFECT_NODE_TYPE_HOA_SPACE_RENDER` | 212 | 26.0.0 | 48 kHz、S32LE、2 声道 | 前置节点必须是 HOA 格式输入节点，否则 `StartPipeline()` 报错 |

系统节点类型（`@systemapi`）为 301 对白增强、302 声音美化、303 节拍器（26.2.0）。

节点创建与连接规则：

- Builder 可复用；新节点属性与上一次不同时必须先调用 `OH_AudioSuiteNodeBuilder_Reset()`。`SetNodeType()` 对所有节点必选。
- 只有输入节点和输出节点可以设置音频格式；效果节点调用 `SetAudioFormat()` 返回 `AUDIOSUITE_ERROR_UNSUPPORTED_OPERATION`，通过 builder 给效果节点设置格式会在 `CreateNode()` 时返回同一错误。只有输入节点可以设置取数回调，输出节点设置回调同样不支持。
- 输入节点未设置回调时创建返回 `AUDIOSUITE_ERROR_REQUIRED_PARAMETERS_MISSING`。
- 连接顺序固定为输入节点、若干效果节点、输出节点；连接是单向的，不允许成环或后序节点反向连接。
- 混音节点支持多路输入，其余效果节点单路输入；音源分离节点后只能接输出节点。
- 连接和断开都会改变拓扑，可能造成部分数据丢失，建议在管线停止时执行。
- 只有效果节点支持旁路；旁路时节点透传数据，不做效果处理。
- `DestroyNode()` 要求所属管线处于停止状态，且节点不在活跃处理路径上，否则返回 `AUDIOSUITE_ERROR_INVALID_STATE`；通过 `CreateNodeDirect()` 创建的节点不受管线状态约束。

| 降噪 | 无业务参数，创建并接入管线后生效，可通过旁路关闭 |

| 空间渲染 | 固定摆位：x/y/z ∈ [-5.0, 5.0] m；旋转：x/y/z 同上，单周时间 [2, 40] s，方向 0 逆时针/1 顺时针；扩展：半径 [1.0, 5.0] m，角度 (0, 360)° |

空间渲染使用左手坐标系：拇指指向 X 轴正方向，食指指向 Y 轴正方向，其余手指指向 Z 轴正方向。参数越界时设置失败并返回 `AUDIOSUITE_ERROR_INVALID_PARAM`。

### 音频格式与帧规格

- `OH_AudioFormat` 由采样率、声道布局、声道数、编码类型和采样格式组成；编码类型当前只有 `AUDIO_ENCODING_TYPE_RAW`。
- 采样率支持 8、11.025、12、16、22.05、24、32、44.1、48、64、88.2、96、176.4、192 kHz 共 14 档。
- 采样格式支持 `AUDIO_SAMPLE_U8`、`S16LE`、`S24LE`、`S32LE`、`F32LE` 共 5 种。
- 输入节点格式表示应用写入的数据格式，输出节点格式表示应用期望取回的数据格式；两者可以不同，由管线内部转换。
- 单帧长度按帧时长计算，默认 20 ms；采样率为 11025 Hz 时必须按 40 ms 计算（输入节点内部转换到 16 kHz、F32LE 处理，输出节点使用双倍帧长）。
- `RenderFrame()` 的 `requestFrameSize` 和 `responseSize` 单位为字节；管线尽量按请求大小填充，实际写入量通过 `responseSize` 返回。
- 输入回调的返回值必须在 [0, audioDataSize] 内，小于 0 按 0 处理，大于上限按上限截断；最后一帧必须把 `finished` 置为 true。
- 所有输入节点的数据都结束后，管线完成剩余处理后通过 `finishedFlag` 通知应用；`finishedFlag` 为 true 后不得继续调用渲染接口，否则返回 `AUDIOSUITE_ERROR_UNSUPPORTED_OPERATION`。
- 管线中含多输出节点时必须使用 `MultiRenderFrame()`：数组元素数量与节点输出路数一致（音源分离为 2 路，人声和伴奏），每路缓冲区大小一致，系统保证各路写入长度相同。

### 实时预览规格

- 实时预览使用 `AUDIOSUITE_PIPELINE_REALTIME_MODE`，在 `OH_AudioRenderer` 的写数据回调中调用 `RenderFrame()`，把处理结果直接写入播放缓冲区。
- 渲染器回调帧长必须与管线计算的单帧长度一致；管线处理耗时随效果节点数量增加，节点过多会导致播放卡顿。
- 实时预览过程中不支持新建效果节点，只支持修改已有节点参数；需要改变拓扑时应停止管线后重建。

### 扩展与系统接口规格

以下除运行时快照为公开接口外，其余均为 `@systemapi`。
- 运行时快照（公开）：`OH_AudioSuite_PrintInfo()` 可输出引擎或单条管线的节点状态；`fd` 小于 0 时写入日志，否则以追加方式写入文件。
- 元数据渲染：`OH_AudioSuiteEngine_MetaRenderFrame()` 同时传递音频和元数据，输入节点通过 `OH_InputNode_RequestMetaDataCallback()` 每次调用取一帧，实际写入量通过 `responseAudioSize` 和 `responseMetaSize` 返回。
- 系统节点：通过 `OH_AudioSuiteNodeBuilderSystem_SetNodeType()` 创建，使用 `OH_AudioSuiteEngineSystem_SetNodeParam()`/`GetNodeParam()` 读写参数，使用 `GetNodeInOutSize()` 查询输入输出帧大小。
- 无管线直连链：`OH_AudioSuiteEngine_CreateNodeDirect()` 创建不属于任何管线的节点，节点之间通过 `ConnectNodes()` 组成唯一一条链；不能与管线节点混连。链级输入输出格式通过 `SetAudioIOFormat()` 一次性设置，首次成功渲染后锁定，直到 `StopNodeChain()`。
- 直连链状态：`StartNodeChain()` 之前 `RenderDirect()`/`Render()` 返回 `AUDIOSUITE_ERROR_INVALID_STATE`；重复启动或重复停止成功且无副作用；停止后节点、连接和参数保留，格式被解锁，可重新设置并再次启动。
- 直连链渲染：`RenderDirect()` 为推模式，应用在同一调用中传入输入帧并取回输出帧；`Render()` 为回调模式，由框架通过 `OH_AudioSuiteEngine_RequestDataCallback()` 拉取输入。每次调用帧长为 256 至 1920 个采样点（48 kHz 下约 5.3 至 40 ms），输入和输出不得指向同一内存，不支持并发渲染和重入。
- 节拍器参数：`stepRate` 范围 60 至 200，`targetBpm` 范围 40 至 240，越界返回 `AUDIOSUITE_ERROR_INVALID_PARAM` 且当前值不变，下一次渲染帧生效；未成功设置前读取返回 `AUDIOSUITE_ERROR_REQUIRED_PARAMETERS_MISSING`。
- 节拍器 profile 缓冲：容量固定 512 KB，由框架创建和持有。固定四步为 `AcquireMetronomeProfileBuffer()` 取得写入权、写入内容、`CommitMetronomeProfile()` 提交、`ReleaseMetronomeProfileBuffer()` 归还写入权；节点存活期间复用同一缓冲，未提交的内容在归还时丢弃，内存随节点或引擎销毁回收。

### PCM 格式转换器规格

- 转换器独立于引擎和管线，只处理 PCM 数据，支持 14 档采样率、32 种声道布局和 5 种采样格式之间的转换。
- 输入通过 `OH_AudioConverter_RequestDataCallback()` 拉取，单次回调最多返回 400 KB；回调返回的数据指针必须保持有效直到 `OH_AudioConverter_Process()` 返回。
- 回调状态为 `AUDIOCONVERTER_INPUT_HAVE_DATA`（有数据，返回值必须大于 0）、`AUDIOCONVERTER_INPUT_NO_AVAILABLE_DATA`（暂无数据，返回 0）、`AUDIOCONVERTER_INPUT_DATA_FINISHED`（输入结束，返回 0）。
- `OH_AudioConverter_Process()` 的输出缓冲区由调用方分配，容量至少容纳一个完整音频帧（采样率 × 声道数 × 采样字节数），不足返回 `AUDIOCONVERTER_ERROR_BUFFER_TOO_SMALL`。
- 输入结束后必须继续调用 `Process()`，直到返回成功且 `outputSize` 为 0，才能确认缓存数据已全部输出；不能仅凭 `outputSize` 为 0 判断整个转换完成。
- 转换器必须显式调用 `OH_AudioConverter_Destroy()` 销毁。

### 云端算法资源下载规格（@systemapi）

- 下载管理由独立 SA 3015（`audio_suite_server`）承载，按需启动，只负责云端算法模型资源的下载、安装和卸载；实时算法处理在应用进程内完成。
- 接口包括获取管理句柄、注册/注销状态回调、开始/暂停/取消/后台下载、查询下载状态、卸载资源，以及 26.0.1 起的批量安装状态、下载状态和新版本查询。
- 状态信息包含特性名、下载状态、大小、安装路径、进度 [0, 100] 和错误码；批量接口要求输出数组容量不小于输入特性数量。
- 特性名必须在服务端白名单内，单次最多 128 个，每个长度小于 256 字节。当前白名单为 `AudioSourceSeparationAlgoRes`、`RecordDefinition`、`RecordDialogAlgoRes`、`RecordPicAlgoRes`、`MusicMasterAlgoRes`，新增特性需同步服务端校验。
- 后台下载受充电、电量、Wi-Fi、亮屏和用户解锁等条件约束，相关条件在 `sa_profile/audio_suite_server.json` 中声明。

| 对象 | 限制 |
| --- | --- |
| 引擎 | 进程级单例 |
| 管线 | 每引擎最多 10 条；API 26.0.0 之前实时预览管线最多 1 条 |
| 输入节点 | 每管线 API 24 之前最多 5 个，API 24 及以后最多 15 个 |
| 输出节点 | 每管线有且只有 1 个 |

| 音源分离节点 | 每管线最多 1 个 |

## 约束与常见误区

- 节点不能脱离管线和引擎单独使用；不要把 builder 当成节点句柄，也不要在节点创建后继续修改 builder 的节点类型而不调用 `Reset()`。
- 效果节点不能设置输入输出格式，其输出格式由节点类型固定；试图通过 `SetAudioFormat()` 修改效果节点会返回 `AUDIOSUITE_ERROR_UNSUPPORTED_OPERATION`。
- 音源分离节点只能连接输出节点，且管线中含有该节点时必须使用 `MultiRenderFrame()`；用 `RenderFrame()` 取不到两路结果。
- 管线停止状态下不能渲染，`finishedFlag` 为 true 后也不能继续渲染；停止管线会清空节点缓存，但不会断开连接。
- 实时预览只允许改参数，不允许增删节点或改变连接；渲染回调的帧长必须与管线单帧长度匹配。
- 管线数量、输入/输出节点数量、混音和音源分离数量均为硬限制，超过时返回 `AUDIOSUITE_ERROR_CREATED_EXCEED_SYSTEM_LIMITS`，不要依赖重试规避。
- HOA 空间渲染节点的前置节点必须是 HOA 格式输入节点，连接不合法时错误到 `StartPipeline()` 才暴露。
- 采样率 11025 Hz 必须按 40 ms 计算帧长；其他采样率按 20 ms 帧长计算，并需与输出节点和播放器回调保持一致。
- 直连链不属于任何管线，不能和管线节点混连；其格式是链级属性，首次渲染后锁定，需重新设置时必须先停止链。
- 不要把 `@systemapi` 的下载、系统节点、直连链和节拍器接口当作三方应用可用能力；也不要把某个产品支持的节点类型写成所有设备的固定能力。
- 云端下载只负责模型资源，不代表算法节点已可用；节点创建仍需通过 `IsNodeTypeSupported()` 检查。

## 安全与隐私

- 所有跨接口传入的指针、长度、数组容量和枚举值必须校验；缓冲区容量与真实分配大小由调用方保证一致。
- 系统接口必须校验调用者身份，非系统应用返回 202；批量接口校验特性名白名单、数量上限和输出数组容量。
- 用户音频、分离结果、变声结果和中间缓存均按敏感数据处理，日志、快照和转储不得包含原始 PCM、用户内容或可识别个人的音频特征。
- 明确缓冲区所有权：输入回调的数据在本次渲染调用返回前有效；转换器回调的数据在 `Process()` 返回前有效；节拍器 profile 缓冲由框架持有，应用只取得写权限。
- 输入帧和输出帧不得指向同一块内存，直连链不支持原地处理；共享缓冲区、文件描述符和下载路径需做边界校验。
- 失败、取消、超时和服务退出后不得残留未释放的管线、节点、转换器或下载任务；模型资源安装路径和完整性由服务侧校验。
