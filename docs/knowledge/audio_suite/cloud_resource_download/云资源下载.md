# 云资源下载

## 范围

云资源下载由独立 SA 3015（`audio_suite_server` 进程）承载，只负责云端算法模型资源的下载、安装和卸载；实时算法处理仍在应用进程内完成。下载管理接口从 API 26.0.0 起为 `@systemapi`，26.0.1 起增加批量查询。编创引擎和管线的整体模型见 [音频编创.md](../音频编创.md)。

## 设计规格

### 服务与启动

- SA 3015 注册在 `sa_profile/audio_suite_server.json`，`run-on-create` 为 false，按需启动；空闲 5 分钟后自动卸载，有下载任务时延长卸载。
- init 配置中进程名为 `audio_suite_server`，UID/GID 为 `audio_suite_server`，SELinux 标签 `u:r:audio_suite_server:s0`，申请 `ohos.permission.GET_NETWORK_INFO`。
- SA 只管理云端模型资源；节点是否可用仍由 `OH_AudioSuiteEngine_IsNodeTypeSupported()` 和本机算法库决定。

### 客户端接口

- `OH_AudioSuite_GetDownloadManager()` 获取管理句柄。
- 注册/注销下载状态回调；状态回调携带特性名、下载状态、大小、安装路径、进度和错误码。
- `OH_AudioSuite_StartDownload()`、`PauseDownload()`、`CancelDownload()`、`StartBackgroundDownload()`。
- `OH_AudioSuite_GetDownloadStatus()` 查询单特性状态；`OH_AudioSuite_UninstallCloudRom()` 卸载已下载资源。
- 26.0.1 起增加批量 `IsFeatureInstalled()`、`GetFeatureStatus()`、`GetNewVersionInfo()`；批量接口要求输出数组容量不小于输入特性数量，`count` 不能为 0。

### 特性白名单与状态

- 特性名必须在服务端白名单内，单次最多 128 个，每个名称长度小于 256 字节。
- 当前白名单：`AudioSourceSeparationAlgoRes`、`RecordDefinition`、`RecordDialogAlgoRes`、`RecordPicAlgoRes`、`MusicMasterAlgoRes`。新增特性需同步服务端校验。
- 下载状态信息包含特性名（`char[256]`）、下载状态、大小、安装路径（`char[256]`）、进度 [0, 100] 和错误码；版本信息包含特性名、下载状态、版本号（`char[128]`）、大小和错误码。

### 后台下载条件

- 后台下载默认要求 Wi-Fi、充电、电量大于 50% 且屏幕处于锁定状态。
- `AudioSourceSeparationAlgoRes` 和 `RecordDefinition` 只要求 Wi-Fi。
- 条件事件通过 `common_event_service` 订阅 Wi-Fi、电池、充电和锁屏变化；`netmanager_base`、`battery_manager`、`screenlock_mgr` 为可选构建依赖，未集成时对应条件判断返回 true。
- 系统参数 `persist.multimedia.audiosuite.download` 和 `persist.multimedia.audiosuite.download.wifi` 由后台下载模块读写，产品需配置对应 param 和 SELinux 权限。

### 权限

- 服务侧所有下载方法要求系统应用权限；非系统应用调用返回 202。
- 更新引擎回调注册/注销和下载状态上报要求调用方 UID 为 `audio_server`。

## 约束与常见误区

- 下载完成不代表算法节点已可用；节点创建仍需通过 `IsNodeTypeSupported()` 检查。
- 特性名不在白名单、数量超过 128 或名称长度达到 256 字节时返回参数错误，不要依赖重试。
- 批量接口的输出容量不足时不会写入部分结果；调用方应先按输入数量分配数组。
- SA 按需启动并自动卸载，调用方需要处理服务未启动或 IPC 失败的情况。
- 后台下载受网络、电量、充电和锁屏条件约束；前台下载与后台下载的触发条件不同。

## 安全与隐私

- 所有下载接口校验系统应用身份；批量接口校验特性名白名单、数量上限和输出数组容量。
- 模型资源安装路径和完整性由服务侧校验；不要信任调用方传入的路径或文件名。
- 下载状态只包含完成请求所需的最小信息，不泄露其他应用或系统内部路径。
- 服务退出、下载取消或超时后不得残留未清理的下载任务和临时文件。
